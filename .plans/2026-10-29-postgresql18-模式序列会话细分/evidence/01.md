## 独立libpq参考观测

参考：PostgreSQL 18.6 on aarch64-apple-darwin25.1.0, compiled by Apple clang version 16.0.0 (clang-1600.0.26.6), 64-bit；server_version_num=180006。未运行18.4，不混用历史结果。

复用既有参考环境文件且不记录DSN/口令。初次不带密码psql连接退出码2（no password supplied），随后使用现有reference.env和pgpass成功；没有修改参考配置或共享对象。

命令如下，Python脚本调用真实libpq的PQexec和PQexecParams（参数数0、文本结果），每协议独立连接：

    source /Users/Shared/work/dir/data/software/postgresql-18.6-reference/reference.env
    python3 /tmp/pg11-01-reference.py > /tmp/pg11-01-reference.log
    PG18_REFERENCE_DSN="$PG18_REFERENCE_DSN options='-c search_path=pg_catalog'" python3 /tmp/pg11-01-reference.py > /tmp/pg11-01-reference-configured.log
    PG18_REFERENCE_DSN="$PG18_REFERENCE_DSN options='-c search_path=public'" python3 /tmp/pg11-01-reference.py > /tmp/pg11-01-reference-public.log

三次均退出码0；每配置2协议×17条输入，共102条参考观测，JSON结果的默认值/空路径/NULL和错误码经Python断言检查通过。独立输入序列：SELECT version(); SHOW server_version_num; SHOW search_path; SET search_path TO ''; SHOW search_path; SELECT current_schema(); SET SESSION search_path = public; SHOW search_path; SET search_path TO pg_catalog; RESET search_path; SHOW search_path; SET search_path TO DEFAULT; SHOW search_path; SET search_path TO; SET SESSION search_path TO NULL; SHOW search_path extra; SHOW search_path。每条独立发送，非多语句结果推测。

| 配置 | 初值/RESET/DEFAULT/失败后SHOW |

| 不覆盖参考配置 | `"$user", public` |

全部配置两协议下，SET SESSION可设置public，空路径SHOW=`""`且current_schema为SQL NULL；三项非法输入均42601，连接随后可读取原路径。libpq options在参考端作为设置默认值的方法，本地功能只消费直接StartupMessage search_path参数，不声称本地支持通用options。
